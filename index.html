Before you start

A few good
questions.

Is this the phone app?

The main download is the Windows receiver. The Android app section provides the signed v50 phone APK. You need both for phone-to-PC controls.

Does portable mean I need no drivers?

The receiver runs from its extracted folder. Some features need separate drivers, such as a virtual gamepad or dedicated virtual display. The receiver checks supported dependencies and shows setup prompts when needed.

Can I stream over Bluetooth?

Bluetooth carries controls only. Use Wi-Fi, Ethernet, USB tethering or a phone hotspot for streaming.

My PC does not appear. What should I check?

Keep the receiver open. For Wi-Fi, connect the phone and PC to the same network. For Bluetooth, turn on both radios and make the PC discoverable for first pairing. If Windows asks, allow receiver access on your trusted private network.

Can a virtual screen keep my laptop free?

A dedicated virtual screen requires a supported, separately installed virtual-display driver. It shares the Windows input session, so simultaneous laptop work also depends on the game accepting background gamepad input.
